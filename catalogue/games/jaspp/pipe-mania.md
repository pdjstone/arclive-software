# Pipe Mania

Pipe Mania is a game of great ingenuity, simple in concept and fiendishly challenging to play.

You'll need to act instinctively, but think strategically!

One wrong move, one brief hesitation or mis-placed pipe section, and you'll drown in a sea of slime!

## Quick Start
Build a pipeline to channel the slime for as long as possible!

Game Controls:
- <kbd>Z</kbd> - Left
- <kbd>X</kbd> - Right
- <kbd>'</kbd> - Up
- <kbd>/</kbd> - Down 
- <kbd>Enter</kbd> - Place piece
- <kbd>Tab</kbd> - Go faster

Title screen:
- <kbd>Space</kbd> - Start game
- <kbd>O</kbd> - Options
- <kbd>L</kbd> - Level jump
- <kbd>K</kbd> - Redefine keys

Options screen:
- <kbd>F1</kbd> - One player basic
- <kbd>F5</kbd> - Two player
- <kbd>F9</kbd> - One player expert

- Player 1: <kbd>F2</kbd> Keyboard  / <kbd>F3</kbd> Mouse
- Player 2: <kbd>F6</kbd> Keyboard / <kbd>F7</kbd> Mouse

- Skill: <kbd>F10</kbd> Training / <kbd>F11</kbd> Standard / <kbd>F12</kbd>  Archimedes Special
